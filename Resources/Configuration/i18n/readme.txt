the folder i18n contains language json files if custom internalization is needed in the Web application
their are the CultureInfo 2A Code + .json with the english excep for the english one :  en-US.json

Examples :
fr.json
de.json
en-US.json

the content of this files is describe in the documentation http://010almdocs.homag.com/WoodProcess/web-prj/internationalization-ui-elements.html
